# 餐馆记账（网页版）

跟安卓 App 功能一样的网页版，iPhone 和安卓手机都能用。数据存在每台手机自己的浏览器里，不经过任何服务器。

## 同事怎么用

**iPhone：**
1. 用 **Safari** 打开链接（微信里打开的话，点右上角 ··· →「在浏览器打开」）。
2. 点下面的「分享」按钮 →「添加到主屏幕」→「添加」。
3. 以后都从主屏幕的「餐馆记账」图标打开。数据存在那里，没网也能用。

> 先加到主屏幕再开始记。在 Safari 里直接用和从主屏幕图标打开，数据是分开存的。在微信里打开的话，首页会提示去浏览器打开。

**安卓：** 用 Chrome 打开链接 → 菜单 →「添加到主屏幕」或「安装应用」。
- 安卓的 Chrome 不让网页直接把 Excel 分享到微信，会存到手机的「下载」里，并提示怎么在微信里发（聊天 → ＋ →「文件」）。统计图片可以直接分享。
- 恢复数据：在微信里把备份文件「保存到手机」，再点「恢复数据」选它；或者在文件管理里长按备份文件 →「分享」→「餐馆记账」（加到主屏幕以后才有）。

## 功能

- 首页：本子按钮（小本、大本、蔬菜、牛肉，可以自己加）和统计分析；右上角「备份数据」「恢复数据」，一周没备份会变红提醒。
- 本子页：清单里的东西都列出来，填数字自动保存。
  - 可以打负数（减掉的），会问原因。
  - 牛肉每箱填一个斤数，一个数就是一箱。
  - 清单里没有的东西可以临时加。
  - 可以查询以前的记录、拍照识别（DeepSeek）、分享当天的 Excel。
  - 底部「预览」：只列这天填了的（按清单顺序，从第一个到最后一个），可以直接加减；「加一样」从清单里挑还没填的加进来。
- 统计分析：
  - 时间段可以点今天、本周、本月、全部，也可以直接选日期，左右箭头往前往后翻。
  - 可以按品名或按日期看，减掉的单独列出来。
  - 可以发图片或分享 Excel。
- 设置：
  - 改本子里的东西，按住 ≡ 拖动排序。
  - 「管理本子」：加、改名、换颜色和图标、拖动排序。
  - 拍照识别设置：填 DeepSeek Key。
  - 把清单发到别的手机。

## 更新

发布新版本后，开着的 App 首页会出现「有新版本了，点这里更新」，点一下就是新版，数据不会丢。关掉再打开也会自动用新版。首页最下面写着这一版是什么时候发布的。

## 跟安卓 App 通用

「备份数据」可以选备份哪段时间的记录（默认全部）；本子、清单、设置（包括 DeepSeek Key）总是全部带上。备份文件（`餐馆记账备份_日期.xlsx`）的格式跟安卓 App 完全一样。安卓的备份可以在网页版恢复，网页版的备份也可以在安卓恢复。

备份里有全部记录、本子、清单和设置（包括 DeepSeek Key），所以只发给自己。发给老板的表格和图片里没有 Key。

## 开发

```bash
npm install
npm run dev      # 本地预览
npm test         # 单元测试（统计、数据库、Excel 读写、拍照识别解析、跟安卓备份互读）
npm run build    # 打包到 dist/
```

推到 `main` 后，GitHub Actions 会自动跑测试、打包，并发布到 GitHub Pages（见 `.github/workflows/pages.yml`）。

代码结构：
- `src/data/`：数据模型和统计（`model.ts`），IndexedDB 存储（`db.ts`），照片上的清单（`seeds.ts`），备份和恢复（`backup.ts`）。
- `src/io/`：
  - `xlsx.ts`：Excel 读写
  - `report.ts`：表格格式，跟安卓的 Report.kt 一样
  - `statsImage.ts`：统计图片
  - `deepseek.ts`、`recognize.ts`、`photo.ts`：拍照识别
  - `share.ts`：分享和下载
- `src/ui/`：页面（`screens/`）、对话框（`dialogs/`）、小部件（`components/`）。
- `src/sw.ts`：service worker（离线缓存、新版本提示、安卓上接收分享过来的备份文件）。
